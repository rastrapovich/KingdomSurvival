# Передать Claude

1. Распаковать архив в отдельную рабочую папку рядом с проектом. Не перезаписывать Assets содержимым всего архива.
2. Открыть **CLAUDE_MASTER_BRIEF_RU.md** — единый большой бриф со всеми состояниями и тегами, этапами и проверками.
3. Для просмотра иконок и примера дуги открыть **PREVIEW.html**. Работает локально, без сети.
4. JSON/CSV в Data — точные снимки, связи, отбор, профили расхождений, назначения и матрицы. Это не готовый исполняемый код Unity.
5. Art/StatusIcons — 89 отдельных SVG и 178 отдельных PNG (256/128). Текст сроков и зарядов рисует игра.
6. Sources — исходные пользовательские HTML, байты не изменены. Их встроенное состояние уже включено в эффективный экспорт.
7. Tools/validate_package.py — проверка комплектности и контрольных сумм, не тест игровой механики.

В этом пакете: 89 состояний; 457 тегов; 176 сохранённых звёздочек, из них 168 действующих боевых; 197 записей корзины; 6 небоевых. Боевых неудалённых тегов — 254. Пилот адресный, не массовая случайная раздача.

Иконки созданы как редактируемые векторные UI-знаки с чёрной конструкцией и матовыми плоскостями по направлению Art Style Canon §10. Это рабочий комплект для внедрения и проверки читаемости, не новый художественный канон. Коллажей и спрайтовых листов нет.

Репозиторий и Unity этим архивом не изменены. Реализацию выполняет Claude по этапам. Сверенный main: 55bc8cc4f981343f29583942a3cd98410b839b5e, 20.11.2026; на машине есть несвязанные изменения, сохранить их.
