# Атласы анимаций существ

Папку заполняет «База анимаций» (Kingdom Survival → База анимаций): одна подпапка на набор, один атлас на ячейку «действие × ракурс». Вручную файлы не переименовывать и не перекладывать — наборы ссылаются на них по GUID.

Картинки хранятся только локально (в git — только `.meta`). Инструкция — `ProjectDocs/ANIMATION_DATABASE_GUIDE.md`.
