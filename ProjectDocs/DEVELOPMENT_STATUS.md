# Kingdom Survival — Development Status

Последнее обновление: 2026-09-01

> Технический журнал фактически реализованного состояния Unity-проекта. Канонические решения фиксируются отдельно в актуальном `KINGDOM_SURVIVAL_GAME_CONCEPT_CANON_RU`.

## 1. Текущий этап

**Этап: стабилизация непрерывного времени и полировка взаимодействия с локациями на глобальной карте.**

Актуальный канон — `KINGDOM_SURVIVAL_GAME_CONCEPT_CANON_RU_v1_6.md`.

Непрерывная стратегическая модель сохраняется:

- партия начинается в `День 1 · 08:00` на паузе;
- календарный день меняется только при прохождении `00:00`;
- `ПУСК / ПАУЗА` не запускает старый `DayResolver`;
- доступны прототипные скорости `×1 / ×3 / ×5 / ×10`;
- выбранная скорость сохраняется при паузе и автопаузе;
- `Space` переключает паузу, если нет блокирующего события;
- армия движется по A* непрерывно;
- обязательные события, обнаружение локации, прибытие, исследование и возвращение используют автопаузу.

## 2. Управление временем и гарнизонами

Сохраняется полировка предыдущего этапа:

- нажатие `ПУСК` само по себе не увеличивает день;
- нижний блок времени расположен рядом с `ПУСК / ПАУЗА`;
- до фактического начала движения подготовленный состав экспедиции можно менять между гарнизонами;
- после первого движения состав фиксируется до возвращения;
- сама пауза не является причиной блокировки состава.

## 3. Карточка локации по ПКМ

Добавлена следующая полировка карты:

- ПКМ по известной локации по-прежнему открывает информационную карточку;
- карточка больше не закреплена в правом нижнем углу;
- после ПКМ она позиционируется непосредственно над маркером выбранной локации;
- по горизонтали и вертикали карточка ограничивается рамками карты, чтобы не уходить за экран;
- при ПКМ по другой локации используется та же карточка, которая переносится к новому маркеру;
- ЛКМ вне карточки закрывает её и продолжает выполнять обычное управление картой;
- `Esc` закрывает открытую карточку;
- кнопка `ЗАКРЫТЬ` сохраняется.

### Содержимое карточки

Карточка показывает существующую информацию:

- название;
- регион;
- угрозу;
- статус;
- расчётное время исследования.

Дополнительно:

- если армия находится именно в этой локации, показывается строка `АРМИЯ НАХОДИТСЯ ЗДЕСЬ`;
- добавлена кнопка `ИССЛЕДОВАТЬ`;
- кнопка активна только когда армия физически находится в этой локации и исследование реально доступно;
- если армия не здесь, локация уже исследована, исследование уже идёт, контент исследования не реализован, не хватает снабжения или есть обязательное решение — кнопка выключена и tooltip объясняет причину;
- запуск исследования из карточки использует существующую непрерывную систему исследования.

## 4. Прибытие в известную локацию

Раньше фактическое прибытие создавало информационную плашку `АРМИЯ ПРИБЫЛА` с кнопкой `ПОНЯТНО`.

Теперь такое прибытие преобразуется в обязательный выбор:

- `ИССЛЕДОВАТЬ`;
- `ОТМЕНИТЬ`.

Поведение:

- симуляция остаётся на автопаузе;
- `ИССЛЕДОВАТЬ` запускает существующее исследование, если оно доступно;
- при нехватке снабжения вариант исследования недоступен;
- если исследование для локации не реализовано или локация уже исследована, вариант исследования отображается недоступным;
- `ОТМЕНИТЬ` не возвращает армию и не меняет маршрут: исследование просто не начинается, армия остаётся внутри локации;
- после решения время не запускается автоматически — игрок сам нажимает `ПУСК`.

### Отдельный сценарий обнаружения

Случайное обнаружение скрытой локации по пути **не изменено**:

- армия останавливается;
- открывается выбор `Исследовать / Продолжить маршрут`;
- `Продолжить маршрут` восстанавливает прерванную цель.

Таким образом обычное прибытие и случайная находка остаются разными по смыслу сценариями.

## 5. Архитектура

Добавлен небольшой Core-helper `LocationArrivalDecisionFactory`.

Он:

- проверяет, что активная армия действительно находится внутри не-waypoint локации;
- преобразует обычное прибытие в существующий формат обязательного решения;
- использует уже проверенную механику исследования из `ExpeditionDecisionSystem`;
- вариант `Отменить` безопасно оставляет армию в локации без телепортации и без автоматического продолжения пути.

UI-полировка вынесена в отдельный partial-файл `PrototypeUIController.WorldMapLocationActions.cs`, чтобы не расширять основной контроллер карты.

## 8. Что проверить в Unity после pull

### Карточка

1. открыть экран `Экспедиции`;
2. ПКМ по известной локации;
3. карточка должна появиться над её кружком, а не в углу карты;
4. ПКМ по другой локации переносит ту же карточку;
5. у края карты карточка не выходит за рамку;
6. ЛКМ вне карточки закрывает её;
7. `Esc` закрывает карточку;
8. кнопка `ЗАКРЫТЬ` работает.

### Кнопка исследования

1. открыть карточку далёкой локации — `ИССЛЕДОВАТЬ` выключена;
2. привести армию в локацию;
3. после обработки плашки прибытия снова открыть карточку;
4. должна появиться строка `АРМИЯ НАХОДИТСЯ ЗДЕСЬ`;
5. при доступном исследовании кнопка активна;
6. запустить исследование из карточки и убедиться, что время остаётся на паузе до `ПУСК`;
7. при нехватке снабжения кнопка выключена.

### Прибытие

1. ЛКМ отправить армию к известной исследуемой локации;
2. дождаться фактического прибытия;
3. время должно автоматически остановиться;
4. должна появиться плашка с двумя вариантами `ИССЛЕДОВАТЬ / ОТМЕНИТЬ`;
5. `ОТМЕНИТЬ` оставляет армию в локации;
6. `ИССЛЕДОВАТЬ` запускает исследование;
7. после любого выбора симуляция сама не возобновляется.

### Регрессия

1. случайно обнаруженная по пути локация всё ещё показывает `Исследовать / Продолжить маршрут`;
2. ЛКМ по карте продолжает задавать маршрут;
3. ПКМ не меняет маршрут;
4. Console без новых compile/runtime/USS/UXML errors;
5. `Window → General → Test Runner → EditMode` → запустить `KingdomSurvival.Core.EditModeTests`.
