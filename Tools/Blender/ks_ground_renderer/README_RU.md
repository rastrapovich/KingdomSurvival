# KS Ground Renderer 2.0 — земля большой карты для Kingdom Survival

Аддон Blender 5.2: большая карта земли → **три файла** для «Базы локаций»:

| Файл | Что это |
|---|---|
| `<карта>_color.png` | Рисунок земли (RGBA 8 бит) — его вы обрисовываете |
| `<карта>_normal.png` | Нормали (RGB 8 бит): R вправо, G вверх, B к зрителю |
| `<карта>_height.png` | Высота (16 бит + покрытие): абсолютная Z Blender |
| `<карта>_manifest.json` | Размеры, сетка, диапазон высоты, ракурс камеры — читает Unity |

Внутри аддон рендерит карту **участками** (с полями, которые обрезаются, — швов нет) и сразу склеивает их в большие файлы. Вся карта в памяти не держится: только полоса участков.

## Установка

Blender → Правка → Настройки → Дополнения → «Установить с диска» → `KS_Ground_Renderer_2.0.0.zip`, включить. Старую версию 1.0.x сначала отключить и удалить (две папки `ks_ground_renderer` одновременно держать нельзя), затем перезапустить Blender.

## Как пользоваться

1. Постройте землю в масштабе (1 BU = 1 м). Положите её в отдельную коллекцию, например `GROUND`. Свет — в другую коллекцию, рядом можно поставить модель человека.
2. Поставьте **ортографическую** камеру под тем наклоном, под которым карта будет видна в игре.
3. 3D-вид → N → вкладка **KS Земля**:
   - **Камера** (пусто — камера сцены), **Земля** — коллекция;
   - **Эталон персонажа** — модель человека (необязательно): покажет его рост в пикселях, а в Unity по нему подгоняется рост людей;
   - **Границы** — объект-рамка, если нужна не вся земля;
   - **Пикселей на метр** — чёткость карты. Кнопка с камерой берёт плотность из кадра камеры при её текущем разрешении;
   - **Color**: «Ровный свет для обрисовки» (по умолчанию) или «Свет сцены»;
   - **Имя карты**, **Папка**.
4. **Проверить** — размер карты в пикселях, число рендеров, диапазон высоты, рост персонажа и «карта ≈ N его роста».
5. **Экспорт**. Blender не замирает: участок рендерится штатным рендером, файлы пишутся между участками. Ход — в строке статуса и в индикаторе внизу. **Отмена** или Esc останавливают экспорт; прежние файлы остаются целыми.

Файлы ложатся в `<Папка>/<Имя карты>/`. Повторный экспорт перезаписывает их. Если `_color.png` вы уже обрисовали прямо в этой папке, аддон его не затрёт: переименует в `<карта>_color_обрисовка_<дата>.png`.

## Масштаб

Карта «в 50–100 раз больше персонажа»: при 64 px/м человек 1,8 м ≈ 115 px. Карта в 100 его ростов — около 11 500 px. Предел — 65 535 px по стороне. Время — примерно 3 рендера на участок (Color, Normal, Height). «Проверить» показывает число рендеров заранее.

**Дополнительно**: размер участка рендера (1024 / 2048 / 4096 — меньше участок, меньше памяти на полосу), Samples для Color, ручной диапазон высоты.

## Дальше — Unity

1. Обрисуйте `<карта>_color.png` целиком: кадр не меняйте, увеличивать можно в целое число раз. Сохраните прямо поверх или отдельным файлом.
2. Unity → **Kingdom Survival → База локаций** → место → вкладка **«Земля»** → «Импортировать экспорт Blender…» → `<карта>_manifest.json` (или перетащите папку).
3. База сама нарежет карту на участки. Обрисованный поверх `_color.png` загрузится как обрисовка; отдельный файл обрисовки — кнопкой «Заменить Color обрисовкой». Normal и Height проверяются по sha256: их не правьте.
4. «Рост людей» → «Подогнать рост людей под эталон».

## Что убрано по сравнению с 1.0.x

Тест участка, перерендер выбранных и продолжение экспорта, выбор участков кликом, сетка в 3D-виде, пресеты и профили, раздельные источники и дополнительные объекты, сохранение полей, превью, «отпечаток» геометрии. Именно отпечаток — перебор всех вершин в Python с записью в JSON — вешал Blender при нажатии «Рендер». Кроме того, PNG после каждого прохода разбирались на чистом Python по байту прямо в обработчике таймера, и окно замирало после каждого участка.
