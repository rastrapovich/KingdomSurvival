# Kingdom Survival — Development Status

Последнее обновление: 2026-08-30

> Технический журнал фактически реализованного состояния Unity-проекта. Он не заменяет канонический дизайн-документ и не повышает прототипные решения до статуса канона.

## 1. Текущий этап

**Этап: новый отдельный экран `Армия`, стабилизация компиляции и drag-and-drop бойцов.**

Основная оболочка интерфейса на этом этапе не меняется:

- слева постоянно остаются `KINGDOM SURVIVAL` и `КОРОЛЕВСКИЕ ДОНЕСЕНИЯ`;
- снизу остаются отдельные `Столица / Армия / Экспедиция`;
- ресурсы и `ХОД` остаются справа снизу;
- `DEBUG` остаётся сверху справа;
- экран `Армия` открывается только в центральной рабочей области.

## 2. Экран `Армия`

Текущий прототип экрана собран по пользовательскому макету:

1. сверху расположены `Командир`, `Сводка похода`, `Запасы отряда`;
2. ниже расположен широкий `Гарнизон столицы`;
3. ещё ниже расположен широкий `Гарнизон командира`;
4. правая часть рабочей области остаётся свободной согласно макету;
5. старые заголовок, описание и лишние текстовые блоки скрыты.

## 3. Карточки бойцов

Карточки упрощены и уменьшены для нового интерфейса:

- имя бойца скрыто;
- уровень и оборона скрыты;
- отдельный текст роли скрыт;
- текст назначения скрыт;
- внутри рамки изображения показывается только тип бойца (`Пекарь`, `Копейщик` и т. п.);
- размер карточки рассчитан на одновременное размещение 4–6 бойцов в широком гарнизоне.

## 4. Drag-and-drop

Текущая реализация рассчитана только на настоящее перетаскивание:

- обычный клик по карточке не должен перемещать бойца;
- после движения мыши начинается drag;
- карточка-призрак следует за курсором;
- зона назначения подсвечивается;
- отпускание над другим гарнизоном переносит бойца;
- отпускание вне гарнизонов отменяет действие;
- при активной экспедиции состав заблокирован.

## 5. Исправление компиляции 2026-08-30

После первого коммита нового экрана Unity показал:

- `CS0104: Object is an ambiguous reference between UnityEngine.Object and object` в `PrototypeUIController.ArmyLayout.cs`;
- `CS0618` для устаревшего `Object.FindFirstObjectByType<T>()` в `PrototypeUIController.ShellLayout.cs`.

Причина: `ArmyLayout.cs` одновременно импортирует `System` и `UnityEngine`, а Unity 6 помечает `FindFirstObjectByType` устаревшим.

Исправление:

- добавлен `PrototypeUIController.UnityObjectCompat.cs`;
- внутри partial-класса `PrototypeUIController` вызов `Object.FindFirstObjectByType<T>()` теперь однозначно разрешается локальным compatibility-helper;
- helper использует актуальный `UnityEngine.Object.FindAnyObjectByType<T>()`;
- это должно одновременно убрать `CS0104` и предупреждение `CS0618`, не меняя логику поиска контроллера.

После импорта требуется ручная проверка Unity Editor, поскольку Unity CI в репозитории отсутствует.

## 6. Канон и временное расхождение

Активный канон остаётся `KINGDOM_SURVIVAL_GAME_CONCEPT_CANON_RU_v1_3.docx`.

В версии 1.3 объединённый экран `АЭ` утверждён как канон. Текущий прототип по прямому запросу пользователя использует отдельные экраны `Армия` и `Экспедиция` для проверки нового интерфейса.

**Канонический документ не изменён.** Разделение остаётся прототипным решением до отдельной команды `утверждаем`, `фиксируем` или `добавь в канон`.
