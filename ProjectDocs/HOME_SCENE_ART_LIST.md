# Образ Дома — перечень рисунков для художника

Статус: **[РАБОЧЕЕ]** — производственный перечень ПР-07А-2 (`PR07_HOME_SPEC.md` §4, правка §0.5). Не канон: не утверждает облик мест, географию или мифологию; рисунки иллюстрируют уже существующие состояния первой главы.

## Как это работает

Экран Дома показывает схему из шести слоёв (`Prototype_Main.uxml`, элемент `home-scene`). Сейчас каждый слой — прямоугольник с подписью. Состояние различается рамкой и подписью, не только цветом.

Если положить рисунок в `Assets/_Project/UI/Resources/HomeScene/` с именем `<слой>_<состояние>.png` (Texture2D), экран подставит его сам — без изменения кода. Рамка и фон-заглушка при этом отключаются, подпись остаётся поверх рисунка. Положение и размер слоя задаются в `HomeScreen.uss` (`.home-scene-<слой>`) или в UI-конструкторе.

Рекомендации: прозрачный фон, один свет и масштаб для всех слоёв, читаемость на ширине экрана 1280 px. Смена состояния должна считываться формой (разлом, вода поверх настила, остановленное колесо), а не только цветом.

## Слои и состояния

| Слой (файл) | Состояние (файл) | Что изображает |
|---|---|---|
| `water` | `water_Normal` | Обычная вода у плотины и мельницы |
| | `water_FloodDisturbed` | Мутная вода после паводка, сбитое русло, мусор |
| | `water_Wrong` | «Неправильная» вода: стоит там, где должна идти (без раскрытия причины, DEC-12) |
| | `water_RestoredOldPattern` | Вода снова идёт по старому руслу |
| | `water_AlteredByNewRepair` | Вода идёт по-новому после нового ремонта |
| `mill` | `mill_RunningNormally` | Мельница работает, колесо в движении |
| | `mill_DamagedOrStopped` | Колесо стоит, настил у колеса разбит |
| | `mill_RestoredOldWay` | Работает, видны следы старого ремонта |
| | `mill_RestoredNewWay` | Работает, заметно новое устройство |
| `dam` | `dam_Intact` | Плотина цела |
| | `dam_Damaged` | Повреждена паводком |
| | `dam_ChosenOld` | Начат ремонт по-старому (материалы, разметка), работа не закончена |
| | `dam_ChosenNew` | Начат ремонт по-новому, работа не закончена |
| | `dam_RepairedOld` | Отремонтирована по-старому |
| | `dam_RepairedNew` | Отремонтирована по-новому |
| `walkway` | `walkway_OldIntact` | Настил у мельницы цел |
| | `walkway_Destroyed` | Разбит паводком |
| | `walkway_RestoredOldWay` | Восстановлен по-старому |
| | `walkway_RebuiltNewWay` | Собран заново, по-новому |
| `yard` | `yard_Broken` | Хозяйственный настил во дворе разбит, лужи |
| | `yard_Repairing` | Ремонт идёт: доски, инструмент |
| | `yard_Restored` | Настил восстановлен |
| `livestock` | `livestock_Calm` | Скот спокоен |
| | `livestock_AvoidingWater` | Скот сторонится водопоя |
| | `livestock_Lost` | Загон полупустой: часть скота унёс паводок |

Итого: 25 рисунков. Слой `yard` появляется только после паводка (до этого он не показывается).

Настил у мельницы (`walkway`) и хозяйственный настил во дворе (`yard`) — разные объекты. Их нельзя рисовать одним предметом.
