# UI Layout Editor — implementation status

Дата: 2026-09-06

## Что работает

- Добавлен отдельный `KingdomSurvival.UILayout` runtime-модуль и editor-модуль, не затрагивающие `KingdomSurvival.Core`.
- Добавлен `UILayoutDatabaseAsset` с референсным разрешением 1920×1080 и зарегистрированным экраном диалога.
- Добавлен Unity EditorWindow `Kingdom Survival → UI Конструктор`.
- В редакторе доступны выбор экрана/элемента, drag, resize за правый нижний угол, точное редактирование Rect, перемещение стрелками (1 px / 10 px с Shift), назначение Sprite/Texture2D, Cover/Contain/Stretch, scale/offset, tint, opacity, Undo, сохранение и валидация.
- Изображение сразу показывается на preview; scale/offset применяются к отдельному фоновому слою и не двигают содержимое UI-элемента.
- Диалоговый прототип подключён к `UILayoutDatabaseAsset`: затемнение, панель, портрет, имя, роль, текст и контейнер вариантов ответа получают геометрию из базы.
- Layout масштабируется от референсного 1920×1080 к фактическому размеру UI Toolkit screen.
- Добавлены EditMode-тесты загрузки и валидации базы.

## Что проверено

- Изменения изолированы от `GameState`, карты, экономики, боя, `ExpeditionDecisionSystem` и `NarrativeDialogueSession`.
- `KingdomSurvival.Core` по-прежнему не получает UnityEngine/UI Toolkit dependency.
- В репозитории добавлены `.meta` для новых Unity assets/scripts/assemblies.
- База содержит уникальные ID и положительные размеры элементов.

## Ограничения и ручная проверка

Подключённое окружение не содержит Unity Editor и в репозитории нет настроенного CI, поэтому C# compilation и Unity Test Runner здесь не запускались.

После Pull нужно:

1. дождаться Unity compilation и проверить Console;
2. открыть `Kingdom Survival → UI Конструктор`;
3. убедиться, что база `KingdomSurvivalUILayouts` подхватывается автоматически;
4. подвигать/масштабировать `Панель диалога` и `Портрет`, назначить тестовую текстуру и сохранить Asset;
5. запустить тестовый диалог через DEBUG MENU и проверить соответствие runtime редактору;
6. запустить EditMode tests.

## Следующий шаг

После проверки инструмента подключать остальные существующие крупные UI-блоки по одному, не превращая v1 в замену Unity UI Builder.
