# Облака тумана войны — бриф для ChatGPT (перерисовка, 5 облаков на вид)

**[РАБОЧЕЕ] · 19.11.2026.** Заказ ассетов. Новую механику не утверждает. Стиль видов — [MAP_VIEWS_STYLE_CANON.md](MAP_VIEWS_STYLE_CANON.md) и [MAP_STYLE_GUIDE.md](MAP_STYLE_GUIDE.md), технический контракт видов — [MAP_VIEWS_ART_BRIEF.md](MAP_VIEWS_ART_BRIEF.md).

## Зачем перерисовка

Первый набор (по 2 облака на вид) в игре смотрится плохо:

- **Обычный:** серое фотографичное облако, похожее на дымку. Нет туши, не похоже на рисованную карту.
- **Сепия:** по краю жёлто-красная кайма и грязные пиксели, контур рваный, местами пропадает.
- **Мрачный:** мягкий дым аэрографом, хотя по канону вид пластилиновый. Почти без объёма и формы.
- Во всех видах облаков мало (2), и они выглядят как вставки из другой игры.

## Где и как облака используются

Глобальная карта, вид сверху под углом. Неисследованная местность закрыта сплошной маской тумана цвета вида, а облака лежат **поверх маски вдоль её границы** и придают ей объём. Когда герой подходит, облако отплывает и тает. Облака **не прячут местность сами** (это делает маска), их задача — красиво оформить край неизвестного.

Цвет маски, на которой лежат облака:

| Вид | Цвет маски тумана |
|---|---|
| classic — Обычный | тёмный сине-серый, около #0E0F12, непрозрачность ~86 % |
| sepia — Сепия | бурый, около #5C452E, непрозрачность ~88 % |
| gloom — Мрачный | почти чёрный сизо-лиловый, около #121017, непрозрачность ~90 % |

На экране облако занимает примерно 8 клеток карты в ширину (при обычном масштабе около 250–450 px). Облака случайно зеркалятся по горизонтали и масштабируются ±30 %, многие стоят рядом и накладываются друг на друга.

## Состав заказа

**15 PNG: по 5 разных облаков на каждый вид.** Внутри вида облака должны быть одной манеры, но с разными силуэтами:

1. длинная пологая гряда (ширина ≈ 3,2 × высота);
2. плотная гряда с одним высоким клубом слева от центра (≈ 2,6 : 1);
3. короткая округлая масса из 3–4 клубов (≈ 2 : 1);
4. рваная гряда с выемкой посередине, две массы на общем основании (≈ 3 : 1);
5. низкая широкая подушка с мелкими клубами по верхнему краю (≈ 3,5 : 1).

Пропорции примерные. Главное — чтобы пять облаков не повторяли друг друга и рядом не давали эффекта «забора».

## Общие требования (все виды)

- PNG, RGBA, **прозрачный фон**. Без подложки, рамки, подписи, неба, земли, коллажа: каждое облако — отдельный файл.
- Холст 2048 px по ширине, облако занимает его почти целиком, по краям поле 3–5 %.
- Вид сверху под углом, как у ассетов карты. **Низ облака плоский или слегка округлый** (облако «лежит» на карте), клубы — сверху.
- Формы 70/25/5: одна-две крупные спокойные массы, несколько средних клубов, редкие мелкие завитки. Без мелкой ряби, шума, зерна, «ваты» из сотни одинаковых шариков.
- **Тело облака непрозрачное.** Полупрозрачность допустима только узкой мягкой полосой по самому краю силуэта.
- **Чистая альфа:** никаких цветных ореолов, жёлтой, белой или красной каймы, отдельных висящих пикселей и пятен. Прозрачные пиксели не должны нести мусорный цвет.
- Без свечения наружу, без тени под облаком, без дождя, молний, лиц и символов.
- Свет сверху слева, как у остальных ассетов карты.
- Облако должно читаться на тёмной маске своего вида. Светлая сторона заметно светлее маски, тёмная сторона уходит в цвет маски.

## Обычный (classic)

Рукописная картографическая иллюстрация в духе остальной карты: спокойная акварельная заливка и **выборочная тёплая тушь**.

- **Контур обязателен:** тонкая тёплая тёмно-коричневая тушь (около #3B2A1E) по внешнему силуэту и по 2–4 главным внутренним клубам. Линия живая, разной толщины, местами прерывается и затухает (MAP_STYLE_GUIDE §2.5: просвет, короткий штрих, редкая точка). Не обводить каждый мелкий клуб и не делать одинаковый пунктир.
- Заливка: светлый тёплый серо-бежевый (около #D9D2C3) со светлой стороны, холодная серо-голубая тень (около #8E949C) снизу справа. Тени цветные, не чёрные.
- Две-три спокойные акварельные отмывки внутри, без фотодетализации.
- Не фотооблако, не 3D, не аниме, не «небо Pixar».

## Сепия (sepia)

Рисованная карта на пергаменте: **коричневая тушь, кремовая непрозрачная заливка, одна-две крупные сепийные тени.**

- **Контур обязателен и сплошной по силуэту:** тёмно-коричневая тушь #3A2412, уверенная линия средней толщины. Внутри — 2–4 линии, отделяющие главные клубы. Окончания внутренних линий свободные, с затуханием.
- Заливка: свет #EFE2C6, отмывка тени #A27A4E, самая тёмная тень не темнее #6E4E30. Только тёплое семейство: без зелени, синевы, серо-лилового, оранжевого и жёлтого.
- Допустима редкая штриховка тушью в тени, по форме клуба (2–6 штрихов на клуб, не сплошь).
- Без зерна бумаги, пятен старения, царапин и пергаментного прямоугольника. Кремовый цвет внутри облака — непрозрачный.

## Мрачный (gloom)

**Матовый пластилин**, как остальные ассеты этого вида (направление The Midnight Walk): облако вылеплено руками из нескольких крупных комков.

- **Контура тушью нет.** Форму дают объём, свет и тень.
- Крупные гладкие лепные клубы с ясными гранями и **немногими широкими** следами пальца или стека. Не россыпь мелких вмятин и не мягкий дым аэрографом.
- Цвет: холодный серо-сизый пластилин. Свет около #6E6C74, основная масса #4C4954, тени внутри объёма сизо-лиловые #2A2433. Самая тёмная часть чуть светлее маски (#121017), чтобы облако не пропадало.
- Матовый, без глянцевых бликов, без PBR-реализма, без ярких мультяшных цветов, без свечения и огней.

## Имена файлов

```
classic/fog_cloud_classic_01.png … fog_cloud_classic_05.png
sepia/fog_cloud_sepia_01.png     … fog_cloud_sepia_05.png
gloom/fog_cloud_gloom_01.png     … fog_cloud_gloom_05.png
```

Номер соответствует силуэту из списка «Состав заказа». Отдать одним ZIP с тремя папками.

## Проверка перед сдачей

- [ ] 15 отдельных PNG, RGBA, прозрачный фон, нужные имена.
- [ ] На тёмной подложке цвета маски вида нет каймы, ореолов и висящих пикселей.
- [ ] Обычный и Сепия — с контуром тушью (Сепия — сплошной по силуэту), Мрачный — без контура, лепной.
- [ ] Пять силуэтов вида заметно разные. Рядом и в зеркале они не дают «забора».
- [ ] В уменьшении до 120 px ширины облако читается как одна спокойная масса.
- [ ] Гамма совпадает с ассетами своего вида: Сепия только тёплая, Мрачный холодный серо-сизый, Обычный — тёплая тушь и цветные тени.

## Как поставить в игру

Разложить PNG в `Assets/_Project/Art/MapFogClouds/<вид>/` (старые 01–02 заменить), затем «Генератор карты» → «Виды карты» → выбрать вид → «Облака тумана войны» → «Собрать из папки». Отдельное облако можно заменить, перетащив PNG в его поле.
