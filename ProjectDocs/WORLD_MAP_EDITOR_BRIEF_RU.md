# Редактор карты свободной игры — бриф

Рабочий документ (25.11.2026), не канон. Статус: **предложение на согласование**. Код по брифу не начат.

Запрос пользователя: отказаться от генерации глобальной карты; автор сам собирает карту, на которой начинает игрок, — с рельефом, водой, дорогами, лесом и зонами, местами, поселениями, привязкой квестов и ассетов. Главное требование — **удобство**: конкретные ползунки, переключатели и графы, без лишней сложности.

## 1. Ради чего (GD01, GD04, GD05, GD11)

**Опыт игрока.** Карта, по которой интересно путешествовать: ориентиры видны с дороги, дороги ведут к людям, лес и болото ощутимо отличаются по пути и опасности, места и истории стоят там, где им положено по смыслу, а не где их поставил случай. Автор может выстроить ритм — спокойные участки, тревожные, первая находка недалеко от лагеря.

**Опыт автора.** Карту можно собрать за вечер грубо и за неделю — подробно. Любое действие видно сразу, любая ошибка отменяется Ctrl+Z, ничего не надо помнить: окно само подсказывает, что сломано.

**Как проверить, что получилось** (критерий приёмки поставки):
1. Автор без программиста собирает небольшую карту: рельеф, река с мостом, 3 деревни с соединёнными дорогами, лес с опушкой, Старая шахта, тайник пилота — **за 1–2 часа**.
2. «Играть отсюда» запускает партию на этой карте; видимое совпадает с проходимым (вода непроходима, мост проходим, лес медленнее).
3. Квест «Тайник у старого русла» встаёт на якорь, поставленный автором, а не на найденную генератором точку.
4. Интерес карты проверяется отдельно от исправности (GD12): проход автором по маршруту «лагерь → первая деревня → место». Внешнего плейтеста брифом не предусмотрено.

## 2. Главный архитектурный принцип: та же карта на выходе

Редактор сохраняет **авторскую карту** (`AuthoredWorldMapAsset`), а кнопка «Собрать» (и автоматически перед игрой) превращает её в уже существующую структуру `GeneratedWorldMap`: `TerrainCells`, `Rivers`, `Roads`, `Bridges`/`BridgeSpans`, `Ledges`, `Villages`, `Landmarks`, `Features`, `Districts`, `SpawnSlots`, `Actors`, `PopulationSources`, старт.

Почему так:
- **Остальная игра не меняется**: навигация по гексам, время и движение, `GeneratedMapPlaces`, поселения, население мира, сохранения, рендер MapLab (`MapLabRegionPlan`, `MapLabGameLive`) уже читают эту структуру.
- Видимое и проходимое не расходятся (принцип §9.9.1 «один источник географии» сохраняется): и разметка гексов, и рисунок строятся из одной собранной карты.
- Сохранение партии по-прежнему хранит собранную карту — правка редактора не ломает начатые партии.
- Высоты: в `GeneratedWorldMap` уже есть поле `Elevation` (сейчас только для показа). Авторская карта высот передаётся в MapLab через уже существующий путь `MapLabHeightSource.ExternalHeightmap`; в сохранение высоты добавляются полем (сейчас `[NonSerialized]`).

Переименование `GeneratedWorldMap` → `WorldMapData` — косметика, делается позже отдельно или не делается.

## 3. Окно «Редактор карты» — компоновка

Меню **Kingdom Survival → Редактор карты**. Одно окно, без вложенных окон.

```
┌───────────────────────────────────────────────────────────────────────────┐
│ Файл ▾  Карта: Пограничье ▾  [Собрать] [▶ Играть отсюда]   ⟲ ⟳   Вид: Схема|Рисунок │
├──────┬──────────────────────────────────────────────────────┬─────────────┤
│Инстр.│                                                      │ Инспектор   │
│ ⛰ Р │                                                      │ (кисть или  │
│ 💧 В │                 ХОЛСТ КАРТЫ                          │ выбранный   │
│ ═ Д  │      (схема — мгновенно; рисунок — MapLab)           │ объект)     │
│ 🌲 З │                                                      │             │
│ 🏠 П │                                                      │ ползунки,   │
│ ✦ М  │                                                      │ переключа-  │
│ 📜 И │                                                      │ тели        │
│ ⚔ Г  │                                       [мини-карта]   │             │
│ ✓ П  │                                                      │             │
├──────┴──────────────────────────────────────────────────────┴─────────────┤
│ Слои: 👁🔒 Рельеф 👁🔒 Вода 👁🔒 Дороги 👁🔒 Зоны ...  │ ⚠ 2 предупреждения │ гекс 41:17, высота 34 │
└───────────────────────────────────────────────────────────────────────────┘
```

- **Слева** — 9 инструментов (§4), горячие клавиши 1–9. Под каждым — 2–4 подрежима кнопками.
- **Центр** — холст. Два вида одной карты:
  - **Схема** (по умолчанию при правке): цветные гексы/зоны, линии рек и дорог, значки. Обновляется мгновенно на каждый мазок.
  - **Рисунок**: живописный MapLab. Перестраивается в фоне после паузы в правке (≈1 с) только в изменённой области, если MapLab это позволит; иначе — по кнопке «Обновить рисунок». Ползунок «Прозрачность схемы поверх рисунка».
- **Справа** — инспектор: настройки активной кисти либо свойства выбранного объекта.
- **Низ** — слои (глаз = показать, замок = запретить правку), счётчик проблем (клик — к месту ошибки), координата и высота под курсором.

Управление холстом единое для всех инструментов: колесо — масштаб, средняя кнопка / пробел+ЛКМ — сдвиг, F — вписать карту, `[` `]` — размер кисти, Shift+колесо — сила кисти, Alt+клик — пипетка (взять высоту, тип местности или объект), Esc — снять выделение, Del — удалить выбранное, Ctrl+Z / Ctrl+Y — отмена/повтор (Undo Unity на всё, включая мазки).

## 4. Инструменты

Каждый инструмент — минимум ручек по умолчанию; редкие — под свёрнутым «Ещё».

### 4.1. Рельеф (1)

Карта высот на всю карту, 16 бит, разрешение — по размеру карты (например 513×513 для 180 гексов; число — рабочее).

| Подрежим | Что делает |
|---|---|
| Поднять / Опустить | Обычная кисть (ЛКМ — поднять, Ctrl+ЛКМ — опустить) |
| Выровнять | Тянет к высоте, взятой пипеткой или первой точкой мазка — площадки под деревни |
| Сгладить | Убирает ступеньки и шум |
| Шум | Добавляет мелкую неровность, чтобы рельеф не был пластилиновым |
| Уступ | Линия кликами → обрыв: верх слева по ходу линии, концы сходят в склон (как `GeneratedMapLedge`). Ползунок высоты обрыва, переключатель «проход на концах» |

Ползунки кисти: **Размер**, **Сила**, **Мягкость края**. Переключатель **«Ступени»** (высоты липнут к уровням — удобно для холмов и плато) и ползунок «Шаг ступени».

**Местность по высоте** (галочка «Авто», включена): холмы/горы/скалы в разметке гексов назначаются сами по порогам высоты и крутизны; два ползунка «Холмы от», «Горы от». Ручная разметка гекса (§4.4) перекрывает авто.

Импорт/экспорт карты высот PNG16 (`Файл ▾`) — для работы во внешнем редакторе.

### 4.2. Вода (2)

| Подрежим | Что делает |
|---|---|
| Река | Линия кликами от истока к устью. Ползунки «Ширина у истока», «Ширина у устья». Русло **само прорезается** в рельефе, вода течёт с монотонным спуском (как в MapLab). Галочка «Проверять уклон»: если река идёт в гору — предупреждение и подсветка отрезка |
| Приток | Начать линию от реки — конец сам прилипает к руслу, ширина сливается |
| Озеро | Кисть заливки до уровня: клик в низину — вода заполняет котловину до заданного уровня (ползунок «Уровень воды»), сухой берег гарантируется |
| Болото | Кисть — тип клетки «Болото» + MapLab-покраска |
| Брод | Клик по реке — брод (проходимая клетка воды) |

Узлы линии: перетащить — двигать, клик по линии — вставить узел, Del — удалить, ПКМ — меню (развернуть, разрезать, удалить линию).

### 4.3. Дороги (3) — главное удобство

Автор ставит **только опорные точки**; путь между ними прокладывает редактор.

- **Клик, клик, клик** — дорога от точки к точке. Между точками путь ищется по цене местности (как в генераторе: обход воды, крутизны, уступов; лес и болото дороже). Ползунок **«Прямая ↔ По рельефу»**: влево — почти по линейке, вправо — обходит каждый холм.
- **Автостыковка** (галочка, включена): если начало или конец ближе **«Радиус прилипания»** (ползунок, по умолчанию 2 гекса) к дороге, деревне или месту — дорога примыкает к ним. Примыкание к середине дороги делает перекрёсток; к концу — продолжение той же дороги. Стыки показываются кружком до отпускания кнопки.
- **Через реку — мост сам.** Пересечение воды ставит мост на сухих берегах (`BridgeSpans`); переключатель на мосту в инспекторе — «Мост / Брод». Галочка «Не пересекать воду» — дорога ищет обход или ближайший брод.
- **Тип**: Дорога / Тропа (тропа — уже, дешевле по проходимости, рисуется тоньше). Ширина — ползунок у выбранной дороги.
- **Кнопка «Соединить деревни»**: проложить недостающие дороги так, чтобы все деревни были связаны с минимальной суммарной длиной, + ползунок «Петли» (0 — дерево, больше — объездные пути) + галочка «Выходы к краю карты». Результат — обычные дороги, которые дальше правятся руками.
- **Кнопка «Тропы к местам»**: от каждого места без пути — тропа к ближайшей дороге.
- Правка: тянуть опорную точку — путь пересчитывается сразу; клик по дороге — вставить точку; ПКМ — «Закрепить отрезок» (больше не пересчитывается, если автор провёл его руками точно), «Разрезать», «Удалить».
- Разметка гексов `Road`/`Trail` и поля вдоль дорог выставляются сами; руками дорогу в клетках рисовать не нужно.

### 4.4. Зоны и местность (4)

Два уровня, оба кистью:

**Тип клетки** (то, что считает игра — проходимость и время): Открытая местность, Поле, Лес, Болото, Холмы, Горы, Скалы, Вода (список v1.50, `WorldMapGameplayTerrainType`). Кисть по гексам + **заливка** (по связной области) + **лассо** (обвести — залить). Галочка «Не трогать воду и дороги».

**Зона** (то, что видит игрок и чем пользуются истории): именованная область — «Глухой лес», «Опушка», «Пашня», «Приречье», «Нагорье» (сегодняшние `Districts`). Рисуется той же кистью или лассо; цвет зоны полупрозрачно поверх схемы.

Настройки зоны в инспекторе:
- **Лес**: «Густота», «Доля хвойных», «Размер деревьев», «Ширина опушки» (MapLab сам делает редеющий край), «Поляны» (частота просветов). Галочка «Глухой» — для встреч и историй.
- **Поля**: «Размер наделов», «Межи», «Ограды».
- Любая зона: «Пул встреч» (выпадающий список из Базы встреч; §4.7), «Опасность» (Низкая / Средняя / Высокая — рабочие ярлыки для населения мира), заметка автора.

Граница леса и зона — одно и то же действие: нарисовал лес — получил и тип клеток «Лес», и зону с опушкой. Отдельно рисовать не нужно (переключатель «Только тип клеток» — если нужна разметка без зоны).

### 4.5. Поселения (5)

- Клик — поставить деревню. В инспекторе: **название** (вводит автор; редактор имена не придумывает), **профиль из Базы поселений** (выпадающий список: услуги, торговцы, корчма, доска), **размер** (1–3), **планировка** (вдоль дороги / у переправы / слобода / рассеянные дворы — `GeneratedMapSite.Family*`), держава (из фракций, пусто — не назначено).
- Под деревней рельеф выравнивается сам (галочка «Выровнять площадку», ползунок радиуса).
- **Старт игрока** — отдельный значок-флажок: перетащить куда угодно; по умолчанию — лагерь у дороги (канон v1.64: новая партия начинается в лагере у дороги). Предупреждение, если старт на воде или отрезан.

### 4.6. Места и ассеты (6)

Палитра справа с поиском и вкладками:

| Вкладка | Источник | Что ставится |
|---|---|---|
| Места | База карты / База локаций | Исследуемые места со своим экраном (Старая шахта и др.): клик — поставить, в инспекторе — скрыто до находки, описание, угроза, время исследования, награда (поля `GeneratedMapSite`) |
| Детали | Правила деталей мест (`Features`) | Сети у реки, кладбище, бурелом — видимое без своего экрана |
| Ассеты | База ассетов / наборы MapLab | Любой одиночный рисунок: камень, курган, крест, отдельное дерево. Перетащить на карту; инспектор — размер, поворот, отражение, тон |

- **Перетаскивание** из палитры на холст; Ctrl+перетаскивание объекта — копия.
- **Кисть ассетов** (переключатель): раскидать выбранные рисунки по мазку с ползунками «Плотность», «Разброс размера» — для валунов, кустов, пней. Ластик — ПКМ.
- Ассет не ложится в воду и на дорогу (галочка «Можно на воду/дорогу» — для лодки, моста-декора).
- «Найти на карте» в Базе ассетов показывает все экземпляры в редакторе (сейчас это есть в Генераторе карты — переносится).

### 4.7. Истории: якоря и встречи (7)

Квест не привязывается к координате — он привязывается к **якорю**.

- **Якорь** — точка или зона с устойчивым ID латиницей (`old-riverbed-cache`), названием и заметкой. Ставится кликом/лассо. ID задаёт автор и не переименовывает после выпуска.
- Мастерская квестов и код истории ссылаются на якорь по ID (сейчас `FreePlayCacheStory` ищет точку на сгенерированной карте сам — переводится на якорь).
- В инспекторе якоря — **кто его использует**: список квестов из Мастерской (через `QuestWorkshopBridge`) и встреч, кнопка «Открыть в Мастерской». В обратную сторону: из окна Мастерской — «Показать на карте».
- Встречи: у зоны или якоря — пул встреч (из Базы встреч), галочка «Только днём/ночью» если поддерживается встречами. Сами условия встреч остаются в Базе встреч, редактор только указывает, **где** их пул действует.
- Фильтр слоя «Истории»: подсветить все якоря без квестов и все квесты, чей якорь не поставлен.

**Граница лора.** Редактор ставит места и называет их, но новый факт мира (кто вырыл шахту, кто похоронен в кургане) через описание места не утверждается — сначала `LORE.md`, по обычному порядку проекта. Валидатор этого не проверит; это правило автора.

### 4.8. Группы мира (8)

Сегодняшние `PopulationSources` и `Actors`, но расставленные руками:
- **Лагерь банды**, **территория зверя** — точка + круг территории (ползунок радиуса), тип группы из Базы существ/отрядов.
- **Обоз, дозор** — маршрут линией по дорогам (прилипает к дорогам, как в §4.3), домашняя деревня, расписание в часах мира.
- Галочка «Появляется после...» не вводится в первой поставке — условия появления остаются за историями.

### 4.9. Проверка (9)

Живая проверка без кнопки — счётчик внизу обновляется после каждой правки; клик по строке — камера к месту, проблема мигает.

Ошибки (мешают «Играть»): старт в воде или отрезан; деревня или место недостижимы от старта; дорога пересекает воду без моста/брода; место или деревня в воде; два якоря с одинаковым ID; квест ссылается на несуществующий якорь.

Предупреждения: река идёт в гору; деревня без дороги; место дальше N часов пути от любой деревни (ползунок N); пустая зона без типа; ассет за краем карты.

Слои-схемы (переключатели, перенос из нынешней вкладки «Проверка»): **время пути от старта** (тепловая карта в часах), проходимость, заметность мест, районы.

**▶ Играть отсюда** — Play Mode новой партии на текущей карте; с Shift — герой сразу в точке под курсором (для быстрой проверки места).

## 5. Удобство — обязательные требования

1. **Всё отменяется** (Undo/Redo Unity), включая мазки рельефа и автопрокладку дорог.
2. **Ничего не теряется**: автосохранение раз в N минут и при закрытии; 5 последних резервных копий в `Library/` (не в git).
3. **Схема мгновенная.** Любой мазок виден в кадре без задержки на карте 180 гексов. Живописный рисунок — догоняет.
4. **Один клик — одно действие.** Никаких диалогов «Вы уверены?», кроме удаления всей карты/слоя.
5. **Умные значения по умолчанию.** Новая карта открывается не пустой серостью, а ровной равниной с открытой местностью и стартом в центре; кнопка «Пустая карта» — размер (50/100/140/180 гексов, как сейчас) и пропорции.
6. **Подсказки на месте**: наведение на инструмент — одна строка «что делает и какие клавиши». Без отдельной справки для обычной работы.
7. **Слои с замком**: можно рисовать лес, не боясь задеть дороги.
8. **Выделение и групповая правка**: рамкой выбрать несколько объектов — двигать, удалять, менять общее свойство в инспекторе.
9. **Сетка гексов** — переключатель (по умолчанию выключена на дальнем масштабе, включается сама на близком).

Не делаем (усложнение без пользы сейчас): слои-версии и ветки карты внутри редактора, несколько карт свободной игры, процедурные «кисти-биомы», ноды/графы генерации, совместная правка.

## 6. Данные и хранение

- `AuthoredWorldMapAsset` (ScriptableObject, модуль `WorldMapVisual` или новый `WorldMapEditor`, Unity-зависимости не в `KingdomSurvival.Core`). Внутри — чистые сериализуемые данные: размер, высоты (16 бит, сжатый base64), типы клеток, зоны, линии рек/дорог с опорными точками и флагами закрепления, деревни, места, детали, экземпляры ассетов, якоря, группы, старт.
- Ядро получает чистый класс `AuthoredWorldMapData` и сборщик `AuthoredWorldMapBuilder.Build(data) → GeneratedWorldMap` в `KingdomSurvival.Core` — тестируется EditMode-тестами без Unity-сцены.
- Карта — это **данные, не растровый ассет**: ассет карты хранится в git (правило «растровые игровые ассеты не в git» сюда не относится; PNG-экспорт высот — не в git). Требует подтверждения — §9, вопрос 3.
- Ссылки на рисунки, места, поселения, встречи — только по ID баз; копий рисунков в карте нет.

## 9. Открытые вопросы пользователю `[ОТКРЫТО]`

1. **Код генератора**: (а) скрыть и оставить как есть; (б) оставить кнопкой «Набросать черновик» для старта новой карты с последующей ручной правкой; (в) удалить после 12Ф-7. Рекомендация — (а) на время поставки, затем (в), если черновик не понадобится.
2. **Правка канона §9.9.1** на «одну авторскую карту свободной игры» — утвердить формулировку перед 12Ф-7.
3. **Ассет карты в git** как данные — подтвердить.
4. **Вид «Рисунок» в редакторе**: допустимо ли, что живописный MapLab-рисунок обновляется с задержкой (секунды) после правки, а мгновенна только схема? Если нужен мгновенный рисунок — это отдельная большая работа над MapLab (частичная перестройка).
5. **Размер первой авторской карты** (50/100/140/180 гексов) и что на ней должно быть к первой проверке — это выбор содержания, не техники.
6. **Seed партии**: оставить для населения и встреч (рекомендация) или сделать каждую партию полностью одинаковой.
