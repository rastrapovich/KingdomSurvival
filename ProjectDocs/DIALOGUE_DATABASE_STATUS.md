# Dialogue Database — technical status

Дата: 2026-09-06

## Реализовано

- Добавлен отдельный модуль `Assets/_Project/DialogueDatabase`, не смешанный с `ExpeditionDecisionSystem` и не добавляющий Unity-зависимости в `KingdomSurvival.Core`.
- Создан `DialogueDatabaseAsset` в `Resources/DialogueDatabase/KingdomSurvivalDialogues.asset`.
- Один источник данных используется для тестовых, сюжетных, побочных, случайных, бытовых и служебных разговоров; категория является метаданными, а не отдельной runtime-системой.
- Диалог хранит ID, название, категорию, производственный статус, комментарий, теги, стартовый узел и произвольное число узлов.
- Узел хранит `Node ID`, говорящего, текст и произвольное число ответов; ответ ведёт в другой узел либо завершает разговор.
- Добавлен справочник говорящих: стабильный ID, имя, подпись/роль и Sprite-портрет.
- Runtime-адаптер превращает записи базы в существующие `NarrativeDialogueDefinition / NarrativeDialogueSession`.
- `NarrativeDialogueNode` расширен необязательным `SpeakerId` без ломки старого конструктора.
- `PrototypeUIController` получил `TryOpenNarrativeDialogueById(string)`. Тестовый мельник больше не прописан репликами в C#: он загружается как `prototype_miller` из базы.
- Диалоговый UI подставляет имя, роль и портрет текущего говорящего; геометрия по-прежнему контролируется отдельным `UI Конструктором`.

## Unity Editor

Меню: `Kingdom Survival → База диалогов`.

В окне доступны:

- поиск по ID, названию, тегам и говорящим;
- фильтр по категориям;
- создание, дублирование и удаление диалогов;
- редактирование метаданных, тегов, стартового узла, узлов и ответов;
- выбор говорящего и переходов из выпадающих списков;
- отдельная вкладка `Говорящие` с назначением портрета;
- встроенный проигрыватель веток без запуска игровой сцены;
- проверка выбранного диалога и всей базы.

## Валидация

Проверяются:

- дубли и пустые ID говорящих/диалогов/узлов;
- пустые названия, реплики и ответы;
- неизвестные говорящие;
- отсутствующий стартовый узел;
- переходы в отсутствующие узлы;
- некорректный `EXIT` с переходом;
- узлы без ответов;
- недостижимые узлы;
- отсутствие любого достижимого выхода из разговора.

Циклы сами по себе не являются ошибкой, если из них существует достижимый выход.

## Тесты и граница этапа

Добавлены EditMode-тесты загрузки дефолтной базы, валидации и преобразования `prototype_miller` в runtime-диалог с сохранением `SpeakerId`.

На этом этапе намеренно не добавлены `Narrative State`, условия показа ответа, проверки навыков, эффекты выбора и универсальная Quest System. Для сюжетных и случайных разговоров сейчас унифицирован формат данных и запуск по ID; условия, когда конкретный ID должен запускаться, остаются ответственностью соответствующей сюжетной/encounter-системы следующего этапа.

Unity Editor и Unity Test Runner в подключённом окружении недоступны. После Pull требуется дождаться компиляции, открыть `Kingdom Survival → База диалогов`, нажать `Проверить все диалоги`, пройти `prototype_miller` во встроенном preview и затем проверить тот же диалог через DEBUG MENU в `Prototype_Main`.
