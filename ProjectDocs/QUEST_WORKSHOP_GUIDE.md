# Мастерская квестов — руководство

Инструмент планирования квестов. Не канон: карточка в мастерской не утверждает ни факта мира, ни сюжетного решения — порядок утверждения прежний (`LORE → … → NARRATIVE`, см. `CLAUDE.md`). Статус записи в документах проекта показывается полем «Статус в документах проекта».

## Где лежит

| Что | Путь | В git |
|---|---|---|
| Мастерская | `QuestWorkshop/Мастерская квестов.html` | нет |
| Проект (источник правды для Unity) | `QuestWorkshop/workspace.json` | нет |
| Ежедневные копии (последние 20) | `QuestWorkshop/backups/workspace-ГГГГ-ММ-ДД.json` | нет |
| Снимок баз Unity для мастерской | `QuestWorkshop/unity-snapshot.json` | нет |
| Исходники и сборка мастерской | `QuestWorkshop/src` | нет |
| Окно переноса в Unity | `Assets/_Project/QuestWorkshopBridge` | да |

Папка `QuestWorkshop/` исключена в `.gitignore` по решению пользователя (18.10.2026). Резервные копии делает сама мастерская; при переносе на другой компьютер копируется вся папка.

## Порядок работы

1. Открыть `QuestWorkshop/Мастерская квестов.html` в **Chrome или Edge** (другие браузеры не умеют писать в папку — тогда «Экспорт и копии» → «Скачать workspace.json вручную»).
2. Один раз нажать «Подключить папку» и выбрать `QuestWorkshop`. Дальше каждое сохранение пишется в `workspace.json`; при следующем открытии браузер может попросить подтвердить доступ одной кнопкой.
3. Планировать: линия, статус, паспорт истории, сцены-планы. Писать реплики — во вкладке «Диалоги».
4. Перед переносом — вкладка квеста «Реализация»: ID диалога Unity, режим переноса, замечания.
5. Unity: `Kingdom Survival → Мастерская квестов`. Окно читает `workspace.json`, показывает по каждой сцене «новая / совпадает / отличается / ошибки» и что изменится. Отметить сцены → «Перенести в Unity». Отмена — Edit → Undo.
6. После переноса окно обновляет `unity-snapshot.json`; его показывают «Из базы Unity» и сравнение во вкладке «Реализация».

## Что переносится

- Сцена с репликами → диалог в `KingdomSurvivalDialogues.asset` (реплики, ответы, условия, проверки, эффекты). У существующего диалога сохраняются иллюстрация сцены, кадрировка и позиции узлов в графе, комментарий разработчика; категория, статус и теги — из сцены, если заданы.
- Новые говорящие → реестр говорящих базы диалогов (портреты задаются в Unity).
- Сцена-встреча (карточка «Unity и встреча») → `EncounterDefinition` в `KingdomSurvivalEncounters.asset`; условия появления сцены — `RequiredConditions`. Флаги, которые встреча читает или ставит, заводятся в реестре флагов, если их там нет.
- **Не переносится** (остаётся планом): цели и Хроника, последствия, паспорт истории, «Авторский замысел — нужен код», подсказка недоступного ответа, переход «после разговора» между отдельными диалогами — его задаёт сюжетный код.

## Режим переноса

- **Каждая сцена — отдельный диалог** (ID у сцены). Так устроены диалоги главы и свободной игры.
- **Весь квест — один диалог** (ID у квеста). Включается сам, если ответы ведут в реплики других сцен или сцены связаны переходом «после разговора» (так создают квест шаблоны мастерской). «Закончить разговор» в сцене с продолжением становится переходом к следующей сцене, узел без ответов получает «…».

## Правила ID

Мастерская хранит ID Unity с префиксами, импортёр их снимает: `ud:<диалог>:<id>` — узлы, реплики, ответы; `unity_person_` — говорящие; `unity_flag_`, `unity_knowledge_` — флаги и сведения; `unity_effect_`, `unity_check_`, `unity_item_`, `unity_mod_` — эффекты, проверки, предметы, модификаторы. Собственные ID мастерской переносятся как есть. ID диалога и встречи — постоянные ID сохранения: после выхода в игру не переименовывать.

## Категории каталога

Каталог группируется по полю «Сюжетная линия»: свободная игра, кризис «Дом на чужой воде» (глава 1 и мотивы Encounter-слоя), сюжетный канон вне режимов, дорожные встречи (действующие и выведенные — в архиве), банки идей по разделам `NARRATIVE.md` и `DEAD_OF_WINTER_CROSSROADS_ADAPTATION.md`. Фильтры: статус разработки, статус в документах, этап карты разработки, режим, связь с Unity. Доска статусов меняет статус перетаскиванием.

## Пересборка (для Claude)

```
node QuestWorkshop/src/build.js                    — собрать HTML (проверяет совпадение имён и теги JSX)
node QuestWorkshop/src/migrate/build-initial.js    — начальный проект из unity-snapshot.json и ProjectDocs
```

Исходники: `src/app.js` — распакованная исходная мастерская с правками; `src/ext/*.jsx` — новые модули (файл проекта, каталог, паспорт, Unity, встречи); `src/ext/10-unity-convert.js` — правила преобразования Unity ↔ мастерская (тот же код используется скриптом переноса). Начальный проект встраивается в HTML и используется только при первом открытии; дальше источник — браузер и `workspace.json`. `build-initial.js` без `--force` существующий `workspace.json` не трогает.

Снимок без окна: `Unity.exe -batchmode -quit -projectPath … -executeMethod KingdomSurvival.QuestWorkshopBridge.Editor.QuestWorkshopWindow.ExportSnapshotBatch`; сверка мастерской с базами: `…QuestWorkshopWindow.VerifyBatch`.
